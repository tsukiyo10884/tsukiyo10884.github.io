### maimai小工具
把以下內容加入書籤
```
javascript:(function(){
    var css='default';
    var code="var s=document.createElement('script');s.src='https://tsukiyo10884.github.io/mai-tools/fetch_data.js?css=" + css + "';document.body.appendChild(s);";   eval(code); })();
```
並在[maimai-net](https://maimaidx-eng.com/maimai-mobile/home/)開啟書籤以擷取資料

※在好友的主頁使用可以擷取好友資料(但會擷取不到自己未解鎖的歌曲)
※css可替換成現有樣式，目前可用：default, modern, cute_pink, cute_blue, fabric_board
